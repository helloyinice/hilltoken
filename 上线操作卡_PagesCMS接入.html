Pages CMS 接入：在手机上改网站

Astro 项目已在工作区 hilltoken-astro/ 搭好，内容抽成了可编辑文件。下面 4 步需要你本人操作（涉及 GitHub 账号授权，无法代劳）。完成后，你在手机浏览器打开 Pages CMS 就能改首页文案、发文章，保存即自动上线。

先看懂这条链路：你在 Pages CMS 里改内容 → 它把改动提交成一个 Git commit，推到 GitHub 仓库 → GitHub Actions 自动运行 npm run build → 构建产物自动部署到 Cloudflare Pages → 网站更新。全程免费，且你的源文件有了版本记录。

04

接通 Pages CMS

  1. 打开 app.pagescms.org，点 Sign in with GitHub 登录。
  2. 首次会要求安装 GitHub App：点 Install，选择「Only select repositories」，勾选刚建的 hilltoken 仓库，确认授权。
  3. 回到 Pages CMS，选择 hilltoken 仓库和 main 分支。它会读取仓库根目录的 .pages.yml（已配好），随即出现两个可编辑区。
  4. 试试：点「首页文案与站点设置」→ 改一句首屏文案 → Save。Pages CMS 会提交 commit，几分钟后网站自动更新。

以后在手机浏览器打开 Pages CMS 就能发文、改文案，不必再碰命令行。
