**一句话结论**：节目里真正给出「零成本建站」方法的是杨攀（第 008 期 1:06:40 起）——静态网页 + GitHub Pages / Cloudflare Pages 免费托管 + 每年几十元域名 + 复制一条指令交给 Agent；而「为什么要建个人网站」的理念最早由向阳乔木在第 007 期 16:03 提出——做一个对 SEO / GEO 友好、能被 AI 抓取的站点。

## 四個关键词

- **GEO / 可抓取**：平台纷纷反爬，自己维护一个对 SEO / GEO 友好的站点，等于给 AI 一个官方信息入口——目的不是流量，是认知。
- **SSOT**（Single Source of Truth）：由自己定义「我是谁、做过什么、怎么联系」，避免被 AI 幻觉曲解。
- **Trusted Network**：友情链接是一种互相认证与背书；XFN 关系标记表达的是发布者声明，不是身份认证。
- **To A**：服务对象是 Agent，因此除给人看的页面，还要有 llms.txt、RSS、语义化 HTML。

## 六步做法

1. 一页 HTML：写清「你是谁 / 在做什么 / 有哪些作品」，纯静态、手机可读。
2. 免费托管：GitHub Pages 或 Cloudflare Pages，二选一。
3. 独立域名：可选；按「首年价 + 两年续费」比价。
4. 给 Agent 读：`/llms.txt`、RSS、`rel="describedby"`、语义化标签。
5. 友情链接：链接真实欣赏的人，可加 XFN。
6. 加入名录：交给 Agent 发 GitHub PR，审核合并后进入 Web 2.0 Next 名录。
