02 / Seven Layers

七层产业链全景

从「卖铲子」到「卖工作流」

七层结构自上而下是：算力芯片 → AI 服务器 → 网络互联 → IDC / 智算 → 推理引擎与 Token 工厂 → MaaS → 应用与 Agent。三条主线贯穿全链：资本开支的融资化、训练向推理的重心迁移、国产非 GPU 路线的崛起。

上游吃肉：芯片与光模块掌握定价权，中国在整机、光模块、液冷、PCB 已全球主导，短板在芯片生态、HBM 与高端交换芯片。中游爬坡：Token 工厂的胜负手是单位算力产出 Token 数乘以大规模稳定交付能力，价格战下毛利能否转正仍待验证。下游分化：应用层的天花板最高，但只有把 Token 嵌进真实工作流、形成迁移成本，才能越过 3% 净利率的低谷。

03 / Token Economy

全链的计量单位，正在重构估值

国家数据局 / IDC 口径

Token 正在从技术术语变成产业的价值尺度。中国日均 Token 调用量从 2024 年初的约 1,000 亿，跃升至 2026 年 6 月的约 500 万亿，较期初放大约五千倍。调用量的爆发把「单位 Token 成本」推到了所有商业模式的核心位置。

市场份额的统计存在「两个第一」的口径之争：按整体 MaaS 平台口径，火山引擎占 45.1% 居首；按语言模型口径，阿里云百炼占 46.6% 居首。同一市场，口径不同，冠军不同。

04 / Capital Map

一条赛道，两种命运

2026 融资与估值

2026 年是 Token 工厂从概念走向资本市场的元年：硅基流动冲刺「Token 工厂第一股」，无问芯穹刷新国内 AI Infra 融资纪录，趋境科技年内融资 24 亿元；海外 Fireworks 估值已达 175 亿美元。热闹之下，负毛利与估值工程的质疑如影随形。

估值锚点：中国倍数更高，毛利却为负

海外 Fireworks 以 175 亿美元估值对应 10 亿美元 ARR，PS 约 17.5 倍，毛利率约 50%；硅基流动 77.4 亿元估值对应 0.55 亿元收入，PS 约 140 倍，毛利率为负。中国独立 Token 工厂的规模比海外小一到两个数量级，一级市场给出的倍数反而更高——这是定价最大的争议点。

招股书深挖：把 −24% 拆开看

整体毛利率 −24% 只是表象。招股书按业务拆分后，暴露了这门生意真正的结构：亏在公有云转售，赚在本地部署。

05 / Cases

三家公司的单位经济对比

生产 · 转换 · 应用

把硅基流动、趋境科技与数式 Oinone 放在同一张桌面上，可以看到三种截然不同的生意：趋境代表上游「把算力炼成 Token」的生产侧，Oinone 代表下游「把 Token 嵌进企业工作流」的应用侧，硅基流动居中做转换。真正值得研究的，是它们各自的单位经济模型。

06 / Harness Loop

WorkBuddy、豆包工作、DeepSeek Harness 在哪一层

Agent = Model + Harness

竞争焦点已从「谁的模型更强」转向「谁的 Harness 更强、谁能把工作流固定下来」。这些工作 Harness 产品本质都是 Token 的消费终端：买推理服务、完成一项工作、按席位加用量收费。它们把 Token 经济的上游与下游接成了一个闭环。

同样使用 Claude Opus，只更换 Harness，复杂任务通过率提高 22.1 个百分点，输入 Token 反而下降 21%。同一模型下的成本与效果差距，很大一部分由 Harness 决定。微软 2026 年 11 月白皮书实测
Upside / 结构性机会

入口即价值

  • 工作流一旦固定，迁移成本形成，付费转化路径清晰。
  • 标准化订阅毛利可达 84.9%，远超卖硬件与卖算力。
  • Agent 放大消耗：每一次点击都向上游触发成百上千次调度。
Caution / 认知误区

三个常见误判

  • DAU 高不等于生意好：3.45 亿 MAU 的 C 端长期未直接变现，差别在企业端付费转化。
  • 套壳产品正被上游回收：Cursor 份额从 41% 跌至约 26%，DeepSeek 把 Harness 免费化。
  • 数据打架时先对齐口径：DAU 与 MAU、年化与财年不可直接相除。
07 / Trade Thesis

Token 贸易：成立条件与压力测试

四重剪刀差 vs 反面解读

产业链上存在四重结构性价差，这是贸易成立的必要条件；但同一组数据也能得出完全相反的结论。两面对照，才不会被单一乐观叙事带偏。

四重结构性剪刀差

01 / 异构

算力与模型生态差

英伟达与昇腾、沐曦、摩尔线程、海光、平头哥的算子互不兼容；下游又要同时调用多个模型。跨芯片、全模型统一 API 是刚需。

02 / 峰谷

闲置算力与绿电差

智算中心平均利用率仅 36.8%，在线推理有昼夜波峰波谷。把非高峰闲置算力折价批售，本质是跨时段套利。

03 / 分级

Token 质量分级差

L1–L3 低价市场靠量化压缩，L4–L5 满血市场要 1M 上下文与 99.9% SLA。同一模型不同 SLA 报价可差数倍。

04 / 账期

结算错配差

行业普遍存在客户与供应商重叠。若能把固定月租改为按用量分成、延后结算，就有机会做成正现金流的周转生意。

四重剪刀差解释了价差从哪来，但不保证价差能被一家贸易商稳定拿到——这是必要条件，不是充分条件。

压力测试：同一事实，两种解读

同一事实乐观解读审慎解读
独立生态仅占 1.5%中转空间巨大，整合早期即是机会窗口。三大云厂已占 87%；同一数字也可读成独立玩家几乎没有空间。
收入 +653%、日均吞吐 5,785 亿需求爆发，规模效应即将兑现。吞吐不等于收入更不等于毛利：同期整体毛利 −24%、年亏 3.45 亿。
公有云 −119% / 本地部署 +82.5%切到本地部署与软件许可就能赚钱。这恰恰证明赚钱的是软件与交付，不是 Token 转售本身。
按用量分成可改善现金流轻资产贸易能实现正现金流周转。分成协议要求极强议价权；新进入者上游照样要预付、下游照样要账期。
四重价差真实存在，但「轻资产贸易枢纽」能否拿到价差，取决于三件事：有没有独占或低成本的货源、有没有锁定流量的场景入口、有没有垫资与信用能力。三样都没有的纯通道，价差会被上下游两头吃掉。综合研判
08 / Blueprint

三端落地蓝图与四条红线

冷启动的经营指标

假设决定进场，行业里已被验证的打法可以拆成三个轻资产环节。核心原则是不囤裸卡、不背固定月租、不做泛 C 端补贴——这三条正是 −119% 毛损率换来的教训。

上游 / 采购

只签分成，不囤裸卡

接入地方国资智算中心闲置产能，签按用量分成或延后结算；采购谷电时段批量额度与异构国产卡低价产能；聚合模型原厂阶梯批发折扣。

中游 / 交易

统一网关与分级定价

搭建高并发容灾路由与标准 Token 折算计费引擎；把货源切成 L1–L3 性价比通道与 L4–L5 满血通道，靠动态路由赚差价。

下游 / 消纳

锁定大流量与对公刚需

以 BYOK 嵌入编码助手与企业智能体；联合地方国资代运营区域 Token 超市，承接政企信创合规与对公统一采购预算。

冷启动必须守住的四条红线

风险点产业现实 / 招股书实证应对护城河硬性验证指标
固定租约压垮毛利2025 年公有云算力成本 5,962.7 万，固定容量冗余导致毛损率 −119%严控固定月租底仓，优先签按调用量分成或阶梯保底通道毛利率 ≥ 15%
账期倒挂大客户要 30–180 天账期，上游多要求预付中小开发者预充值；政企绑 3–5 年消纳闭口协议并匹配上游账期净营运资金周转天数 ≤ 0
降智与 SLA 违约低价中转常偷偷量化、缩上下文，生产级客户流失全链路可观测探针，隔离批售与满血通道，明码标价生产通道 SLA ≥ 99.9%
合规与跨境监管生成式 AI 暂行办法、内容标识办法与管制持续收紧境内数据不出域、全量审计日志；海外业务独立主体隔离合规审计 100% 覆盖

账期倒挂与 SLA 可审计，恰是国资背景主体能做出差异化的地方：有信用、有对公渠道、能签消纳闭口协议。但前提是借一个真实场景（被投企业、拟上市企业的 AI 改造）作为消纳底盘，而不是先建通道再找流量——顺序反了，就会回到发券拉新、亏损换规模的老路。

09 / Conclusion

四条结论与五个观察窗口

产业链结构判断
01 / 稀缺

价值在卡脖子处沉淀

芯片、光模块、先进封装掌握定价权；短板在芯片生态、HBM 与高端光芯片。

02 / 效率

中间层在打效率战

Token 工厂胜负手是单位算力产出与稳定交付；毛利转正取决于效率提升是否快于单价下降。

03 / 工作流

闭环的尽头是工作流

项目制应用净利最薄，标准化订阅天花板最高；把 Token 嵌进真实工作流才有迁移成本。

04 / 贸易

可做，但不能做纯通道

转售 Token 不赚钱，软件、交付与场景才赚钱；进场须有独占货源、场景入口或垫资信用至少一样。

值得持续跟踪的五个观察窗口

#观察指标为什么重要
1云巨头自由现金流能否回正、CoreWeave 与甲骨文信用利差决定这轮资本开支潮是消化回吐还是信用事件
2国产芯片出货能否转化为集群交付、液冷与先进封装订单验证国产超节点是真实产能而非纸面份额
3MaaS 单位 Token 成本下降与单价下降的速度差判断 Token 工厂能否从负毛利转正的核心

5Harness 产品的付费转化率与推理成本的赛跑下游需求能否持续兑现，是闭环最大的不确定项

各生态位的战略结论：算力芯片价值最集中但门槛最高；服务器赚制造的钱；网络互联中国已全球主导；IDC 看利用率拐点；Token 工厂最热也最险；MaaS 是云厂主场；应用与 Harness 天花板最高，但需要场景纵深而非套壳。本文为产业链结构梳理与信息归纳，不构成投资建议。
